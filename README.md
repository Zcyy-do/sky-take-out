苍穹外卖（Sky Take Out）
黑马程序员 Java 项目实战《苍穹外卖》——最适合新手的 SpringBoot + SSM 企业级项目实战

本项目是专门为餐饮企业（餐厅、饭店）定制的一款软件产品，包括系统管理后台和小程序端应用两部分。系统管理后台主要提供给餐饮企业内部员工使用，可以对餐厅的分类、菜品、套餐、订单、员工等进行管理维护，对餐厅的各类数据进行统计，同时也可进行来单语音播报功能。小程序端主要提供给消费者使用，可以在线浏览菜品、添加购物车、下单、支付、催单等。

相较于之前的《瑞吉外卖》项目，苍穹外卖的业务更加真实完整，用户端改为微信小程序，加入了统计报表、来单提醒、客户催单、订单管理等功能，业务实现了闭环，技术选型更加丰富和实用。

项目来源：B站黑马程序员《苍穹外卖》

🚀 快速开始
1. 前端管理端
解压 nginx-1.20.2.zip 文件

进入目录并启动 Nginx：

bash
cd nginx-1.20.2
start nginx        # Windows
或
./nginx            # Linux/Mac

2. 小程序用户端
解压 mp-weixin.zip 文件

使用微信开发者工具打开解压后的目录

在微信开发者工具中预览和调试小程序

3. 数据库配置
创建数据库：

sql
CREATE DATABASE sky_take_out;
USE sky_take_out;
导入 sky-take-out.sql 文件

在 application-dev.yml 中配置数据库连接信息

4. 后端服务
确保已安装 JDK 8+ 和 Maven 3.6+

在项目根目录下运行：

bash
mvn spring-boot:run

5. Redis 配置
确保已安装并启动 Redis 服务器
在 application-dev.yml 中配置 Redis 连接信息
